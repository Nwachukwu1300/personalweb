Engineering knowledge graph (RAG)

Problem

Engineering knowledge was spread across thousands of technical manuals that reference, replace and build on each other, so one answer could sit across many documents.

What I did

Led the project. Built a pipeline that extracts and cleans text from the PDFs, a custom spaCy model that spots document codes, and relationship extraction that labels whether one manual references or supersedes another. Then a RAG assistant on top.

What changed

Thousands of linked manuals became one knowledge graph engineers can query, supporting infrastructure asset management.

under the hood

An internal National Highways tool, so GitHub shows the approach rather than the full build.

03 · personal build · systems

CUDA Transformer from scratch

Problem

Most ML work is a config file pointed at someone else's library. I wanted to prove I understood the machinery underneath.

What I did

Wrote CUDA kernels by hand (tiled matmul, warp-shuffle softmax, tiled attention) and my own autograd engine, then trained one decoder on text and on MovieLens 1M without changing it.

What changed

Tiled attention runs 25.7x faster on a Tesla T4 than my CPU version at sequence length 1024, it scores 98% on MNIST, and it runs live as a movie recommender.

under the hood

25.7x compares the tiled CUDA kernel on a Tesla T4 with the dense CPU attention from the same repo, at sequence length 1024. Every number is in BENCHMARKS.md.

05 · dissertation · forensics

Sentinel vehicle identification

Problem

Crash investigators need to know exactly which car was involved, and how safe it is, often from a single photo.

What I did

Built a two-branch ResNet50 that predicts make, model and year with calibrated confidence, trained on Stanford Cars (8,144 images, 196 classes), and matched to Euro NCAP safety ratings.

What changed

46 ms model inference per image. Make 96.4%, model 91.0%, year 89.1%, and 81.7% with all three right.
